## 💼 Featured Projects

### 📊 NextGestCo ERP
**Technologies:** Laravel, MySQL, TypeScript, React, RAG
* ERP system for managing inventory, purchasing, sales, payments, and financial operations.
* Integrated an AI assistant based on Retrieval-Augmented Generation (RAG) to provide intelligent analysis from ERP data.
* Integrated Google Sheets synchronization using Laravel Queues to automate data exchange.

### 📱 Pneumatique Bousta
**Technologies:** Flutter, Dart, Laravel, SQL Server
* Mobile inventory management application connected to a Laravel API.
* Multi-database architecture for centralizing data from multiple SQL Server databases.
* Secure authentication using Laravel Sanctum.
* Synchronization and management of products, depots, and statistics.

### 💧 Mawater
**Technologies:** Laravel, React, REST API
* Water meter management and billing platform developed for the Ait Daoud association.
* Management of subscriptions, payments, and invoice generation.
* REST API architecture connecting the React frontend with Laravel backend.
